NOVIDADE V9
Os adicionais podem ser pedidos em quantidade. Ex.:
- 3x Ovo frito
- 2x Porção de arroz

Por padrão, adicionais usam quantidade ilimitada. No ADM, a opção "Quantidade" pode ser desligada ou pode ser preenchido um limite. Campo vazio = ilimitado.

SUPABASE
Antes de publicar esta versão, execute:
  supabase/MIGRACAO_QUANTIDADE_ADICIONAIS_V9.sql

O restante do projeto e do banco é mantido.


IMAGEM DO LINK / WHATSAPP
- Arquivo usado no preview do link: assets/whatsapp-preview-v2.jpg
- As páginas index.html e restaurante.html já saem com meta tags Open Graph e Twitter Card.
- Depois de publicar ou atualizar no GitHub Pages, o WhatsApp pode demorar um pouco para atualizar o cache do preview.
- Mensagens já enviadas não atualizam retroativamente. Reenvie o link em uma nova mensagem.
- Para atualizar o cache da Meta, use o Sharing Debugger e solicite uma nova extração da URL canônica.
- Para diagnosticar o cache do cliente, também é possível enviar temporariamente a URL com um parâmetro novo, por exemplo: ?preview=20260827.
